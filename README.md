# Carnelian Cascade

Full-colour Python 3 neon match-3 kiln arcade for [ElbowOS](https://x.com/ElbowOS).

Slide a gold cursor across a 6×8 gem kiln. Swap adjacent stones to cut runs of three or more. Cascades chain and score multiplies. Arrows / WASD move. Space / Enter swap.

## Play

```
pip install -r requirements.txt
python3 carnelian_cascade.py --play
```

## Record a 9:16 reel

```
python3 carnelian_cascade.py --record
```
